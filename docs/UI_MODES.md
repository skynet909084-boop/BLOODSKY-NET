# BLOODSKY NET — простой и профессиональный режимы

Версия 0.34.0-dev. Визуальный стиль сохраняет фирменную тёмно-синюю палитру BLOODSKY.

## Простой режим — по умолчанию

Пять разделов: **Главная, Мои устройства, Карта сети, Мой Wi-Fi, Проблемы**.
На первом запуске: небольшая подсказка «Сканировать сеть» и описание трёх шагов.
Кнопка **«? Как пользоваться»** остаётся доступной после закрытия подсказки.
Сканирование запускается только по явному нажатию, подсказка ничего не сканирует.

## Для специалиста

Переключатель «Специалист» возвращает **все 11 существующих разделов**,
включая Wi-Fi RADAR, NETWORK TIME MACHINE, порты SNMP/LLDP и TLS-датчики.
Режим меняет **только видимость пунктов навигации и пояснения**, а не их
содержимое, сетевые права или данные. Все результаты и настройки остаются общими.
Выбор режима и закрытие подсказки хранятся локально как безопасные булевы флаги
в уже существующей таблице SQLite `preferences`. Никакие секреты не сохраняются.

## Значения индикаторов

- Отсутствие ICMP-ответа не доказывает, что устройство выключено.
- Сигнал Wi-Fi в процентах Windows не равен скорости, RSSI или уровню помех.
- Карта не подтверждает физические кабели без LLDP/SNMP.
- DETECTIVE даёт вероятностные выводы, не окончательный диагноз.

## Перед выпуском стабильной 1.0

Нужны UX-приёмка обычными пользователями, проверка навигации на Windows 10/11
при масштабе 100/125/150%, аппаратная приёмка и испытания защищённого обмена
между двумя реальными Windows-компьютерами. Автоматические GUI-smoke и CI их не заменяют.

# BLOODSKY NET — дорожная карта

Цель: локальная Windows-программа, которая помогает не просто находить устройства,
а объяснять **что изменилось, где вероятный сбой и на каких фактах основан вывод**.

| Этап | Результат | Трекер |
| --- | --- | --- |
| 1.0 | Реальные испытания Windows 10/11 и SNMP, стабильный установщик; не выпускать без приёмки | [#15](https://github.com/skynet909084-boop/BLOODSKY-NET/issues/15) |
| 1.1 | LIVE MAP 2.0: интерактивная карта, порты, VLAN, доверие к связям | [#16](https://github.com/skynet909084-boop/BLOODSKY-NET/issues/16) |
| 1.2 | TIME MACHINE: история снимков, сравнение изменений | [#17](https://github.com/skynet909084-boop/BLOODSKY-NET/issues/17) |
| 1.3 | DETECTIVE: офлайн-диагностика одной кнопкой с доказательствами | [#18](https://github.com/skynet909084-boop/BLOODSKY-NET/issues/18) |
| 1.4–2.0 | Wi-Fi RADAR и распределённые измерительные агенты | [#19](https://github.com/skynet909084-boop/BLOODSKY-NET/issues/19) |

## Инженерные принципы

- По умолчанию чтение и явное разрешение на активное сканирование.
- Пунктирные/логические и подтверждённые LLDP-связи никогда не смешиваются.
- Отсутствие информации не означает отключение устройства.
- История и выводы имеют метку времени и источник наблюдения.
- Локальная работа без обязательного облака; никаких паролей в логах/отчётах.
- Новые функции: ветка → тесты → Windows CI → PR → `develop`; `main` только после приёмки.

До завершения #15 текущая версия — **0.9.0-rc1**, не 1.0 stable.

# BLOODSKY NET — карта и идентификация 0.36.0-dev

- Карта открывается отдельным **полноэкранным окном** с Esc/F11, прокруткой, масштабом 75–200%, перетаскиванием и паспортом выбранного узла.
- Теперь на карте можно показать до 512 IP-записей за один проход. Это не равнозначно числу физических устройств или обнаруженным кабелям.
- Имя: обратная запись DNS PTR, затем необязательная Windows NetBIOS `nbtstat -A` (только UNIQUE <00>). Результат NetBIOS не гарантирован.
- Производитель: локальная база OUI `pymanuf`, без передачи MAC наружу. OUI указывает владельца блока адресов, а не модель. Для локального/рандомизированного MAC производитель неизвестен.
- Тип по IP, портам и имени — предположение.
- Пользователь может указать собственную подпись, которая сохраняется после нового сканирования и перезапуска. Сетевое имя не подменяется.

**Реальная приёмка Windows всё ещё нужна:** испытать полный экран на дисплее с масштабированием 100/150%, общее число узлов, DNS и NetBIOS, рандомизированные MAC, а также сохранение подписи после повторного поиска.

# DISTRIBUTED PROBES — офлайн-обмен измерениями, 0.26.0-dev

## Как проверить сеть с двух компьютеров

1. Установите ту же версию BLOODSKY NET на два Windows-компьютера; выполняйте измерения только в сети, которой вы вправе управлять.
2. Включите мониторинг и дождитесь свежих ICMP-ответов; в разделе **«Точки наблюдения»** задайте каждому компьютеру отличающееся имя (например, `Серверная` и `Приёмная`).
3. На каждом компьютере нажмите **«Сохранить мои измерения»**. Приложение экспортирует только свежие (< 180 с) ICMP-результаты, полученные в текущем сеансе. Старый инвентарь не выдаётся за текущий опрос.
4. Перенесите JSON на одно рабочее место способом, разрешённым вашей организацией, и нажмите **«Импорт JSON»** для каждого файла.
5. Нажмите **«Сравнить»**. Программа сопоставляет общие IP только в интервале 5 минут; ответы могут отличаться из-за маршрутов, ACL, запрета ICMP, межсетевого экрана или временных сбоев.

## Ограничения и приватность

- Это **первая офлайн-версия**: никакого фонового сервера, передачи по сети, автоматического поиска соседних компьютеров или удалённых команд. Нет необходимости открывать входящие порты.
- В экспортируемых JSON содержатся IP, имена точек (введённые пользователем), статус ICMP и время измерения. Не экспортируются учётные данные SNMP, MAC, Wi-Fi и полный инвентарь.
- Происхождение и целостность JSON **не аутентифицированы**. Передавайте файлы через доверенные каналы; программа не утверждает, что имя источника или измерения криптографически подтверждены.
- Нельзя доказывать физическую аварию или отключение устройства только по отсутствию ICMP. Разные результаты — сигнал проверить маршруты, правила доступа и повторить измерения.
- Пакеты сохраняются локально до 7 дней, максимум 256 снимков. Один файл ограничен 512 КБ, 256 адресами и требует строгой структуры JSON. Дубликаты идентификаторов игнорируются.
- Для будущей версии с автоматическим обменом обязательны явное подключение, аутентификация источника и шифрование; **пока этого функционала нет**.

Стабильный релиз 1.0 требует отдельной аппаратной приёмки на реальных Windows-компьютерах и сетевом оборудовании.
